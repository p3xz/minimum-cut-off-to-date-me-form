# Minimum Cut-Off To Date Me

A 20 facial metrics form, 5 marks each, 100 total, with a cut-off (default 80) to decide if someone clears it to date the form owner.

Live: https://p3xz.github.io/minimum-cut-off-to-date-me-form/

## How it works

Fill in name, Instagram, and age, then tap 0 to 5 on each metric. The total updates live out of 100, and the verdict is Cleared, Waitlist, or Rejected based on the cut-off. Use Copy result to share the score.

The 20 metrics are grouped in six sections, with ideal values from the original sheet.

## Age rule

18+ only. Under 18 shows an error and is not eligible to apply.
